Snake2D Starter para Unity 6

COMO INSTALAR
1. Feche o Unity ou deixe-o aberto.
2. Extraia o conteúdo desta pasta para a pasta raiz do seu projeto Unity (a pasta que contém Assets, Packages e ProjectSettings).
3. Volte ao Unity e aguarde a compilação dos scripts.
4. No menu superior, clique em Tools > Snake 2D > Create or Reset Snake Scene.
5. A cena será salva em Assets/Scenes/SnakeGame.unity.
6. Pressione Play para jogar. Use as setas ou WASD. A comida vale 10 pontos.
7. Para sair do Play Mode, pressione o botão Play novamente.

NOTAS
- Este starter cria objetos e interface simples por código, sem precisar importar sprites.
- A interface usa OnGUI para reduzir configuração manual. Depois você pode substituir por Canvas/UI mais elaborado.
- Se o Unity mostrar erros, abra Window > General > Console e envie uma captura.
- Faça backup antes de usar “Create or Reset Snake Scene”: essa ação cria uma cena nova e substitui a cena atualmente aberta no editor.
- Este é um ponto de partida didático; teste o jogo e revise o código antes de entregar.
