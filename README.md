# SNAKE

## DESCRICAO
Jogo Snake 2D desenvolvido em Unity e C# para o trabalho individual da disciplina de Desenvolvimento de Jogos Digitais.

## COMO JOGAR
- Use as setas do teclado ou as teclas W, A, S e D para movimentar a cobra.
- Coma a comida para aumentar o tamanho da cobra e ganhar pontos.
- Evite colidir com as paredes ou com o proprio corpo.
- Preencha todo o tabuleiro para vencer.
- Ao perder ou vencer, utilize o botao na tela para jogar novamente.

## CONTROLES
- Setas do teclado ou W, A, S, D: movimentar a cobra.
- Espaco ou Enter: iniciar ou reiniciar a partida.

## TECNOLOGIAS
- Unity 6
- C#

## COMO EXECUTAR
- Abra o Unity Hub.
- Selecione a opcao para abrir um projeto existente.
- Escolha a pasta raiz deste projeto.
- Abra a cena principal do jogo.
- Execute o jogo pelo botao Play.

## OBJETIVO
- Comer a comida, crescer e acumular pontos sem colidir com as paredes ou com o proprio corpo. A vitoria acontece quando a cobra preenche todo o tabuleiro.
